# Pong

Pong from `pong_min.xml`, written as one web page of its own in plain JavaScript.

| File | What |
|---|---|
| `pong_min.html` | the game: its numbers, its things, its rules, and the canvas they are drawn on |
| `LICENSE` | the licence (MIT) |

## Play

Open `pong_min.html` in a browser. It needs nothing else: no build, no server.
