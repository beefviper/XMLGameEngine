# Breakout

Breakout from `breakout.xml`, written as one web page of its own in plain JavaScript.

| File | What |
|---|---|
| `breakout.html` | the game: its numbers, its things, its rules, and the canvas they are drawn on |
| `LICENSE` | the licence (MIT) |

## Play

Open `breakout.html` in a browser. It needs nothing else: no build, no server.
